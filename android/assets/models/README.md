# OtakuDub Bundled AI Models

This directory stores verified offline AI model files.

Planned model files:

- whisper.bin
- otakumind.gguf
- translator.bin
- speaker.bin
- hindi_voice.onnx
- english_voice.onnx

Model files must be compatible with their respective
native inference engines.

Do not add placeholder or empty model files.

Large model files will be downloaded during GitHub
Actions builds rather than committed to GitHub.
